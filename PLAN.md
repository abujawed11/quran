## Completed

### Phase 1 — Layout & Foundation
- Two-panel layout: sidebar (300px) + fixed page panel (fills remaining width)
- Quran page never shifts or jumps — fixed viewport, nothing above or below it
- Decorative Quran page frame: double gold border, parchment gap, diamond corner ornaments
- Fixed aspect-ratio frame (`0.7/1`) — consistent page size across all 610 images
- `object-fit: contain` so varying-dimension images fit without distortion

### Phase 2 — Quran Metadata & Navigation
- `src/data/quranMeta.js` auto-generated by `scripts/gen_quran_meta.js`
- Page mappings derived from actual coords files — Hafizi 15-line 610-page mushaf
- Juz boundary correction: if boundary ayah is not first on its page, uses next page (matches printed mushaf header position)
- Sidebar sections: Current Location (Juz / Surah / Ayah / Page), Navigate (Surah dropdown, Juz dropdown, Page input, Prev/Next), Reciter selector, Debug toggle
- Navigate by Surah → jumps to first page of that surah
- Navigate by Juz → jumps to correct page matching printed mushaf جزء header

### Audio — Basic
- Ayah click plays MP3 from `public/audio/{reciter}/{surahAyah}.mp3`
- 3 reciters: Mishary Alafasy, Abdullaah Al-Juhaynee, Abdurrahmaan As-Sudais
- `audio.load()` before `play()` to prevent beginning cutoff
- `visibilitychange` handler wakes media pipeline on tab return (prevents idle glitch)
- Download script: `scripts/download_audio.sh` — downloads all 6236 ayahs, resumable, retries

### Scripts
- `scripts/download_audio.sh` — bulk audio downloader with resume + retry
- `scripts/gen_quran_meta.js` — generates quranMeta.js from actual coords files

## Phase 3.5 — Full-Surah Playback (Next)

### Concept
- In addition to ayah-by-ayah playback, user can play a **complete Surah MP3 file** (one file per surah per reciter)
- This gives uninterrupted, gap-free recitation — no stitching of individual ayah files
- No per-ayah timestamps in this phase; ayah highlighting is not active during full-surah playback
- Timestamps can be added later (see "Future: Timestamps" below)

### Audio Files
- Folder: `public/audio/{reciter}/full/{001-114}.mp3`
- Naming: 3-digit zero-padded surah number (e.g. `001.mp3`, `002.mp3`, ... `114.mp3`)
- One folder per reciter, same reciter IDs as ayah files
- User drops their surah files in the folder and renames to this convention

### UI — Navigator Sidebar
- A **▶ Play Surah** button placed next to the Surah dropdown in the Navigator panel
- Clicking it plays the full-surah file for the currently selected surah from the start
- No ayah-level highlight shown during playback (surah-level only)
- AudioPlayer bar shows: "Now Playing — Surah Al-Baqarah (Full)" (no ayah number)

### Playback Mode
- New play mode: `"surah-full"` (alongside existing `"single"` and `"continuous"`)
- Uses a separate audio source URL: `/api/audio?r={reciter}&surah=full&f={001}`
  (or direct path `/audio/{reciter}/full/001.mp3` if no proxy needed)
- `playingAyah` state during full-surah mode: `{ surah, ayah: null, displayAyah: null, mode: "surah-full" }`

### Auto-Advance (Surah → Next Surah)
- User-toggleable (separate toggle or reuse existing auto-advance toggle)
- When surah file ends:
  - **ON** → automatically load and play next surah's full file (surah + 1)
  - **OFF** → stop playback
- At surah 114 → always stop

### Future: Timestamps (not in this phase)
Three approaches discussed:
1. **Forced alignment** (WhisperX / Aeneas) — auto-detects ayah boundaries from audio; medium difficulty, high accuracy
2. **Sum ayah MP3 durations** — calculate cumulative start times from existing ayah files; easy, but only valid if full-surah file = exact concatenation of ayah files
3. **Pre-existing datasets** — Quran.com / EveryAyah.com provide timing JSON per reciter; easiest if available for the reciter
Once timestamps exist, ayah highlights can track position in the full-surah file during playback.

---

### Ayah Playback Strategy
- Use existing ayah-by-ayah MP3 files (already downloaded)
- No timestamps or full-surah files needed
- Preload next ayah using a second hidden `<audio>` element (ping-pong buffering) to minimize gap between ayahs

### Right-Click Context Menu on Ayah
- Left-click → selects ayah (shows in sidebar), plays single ayah only
- Right-click → context menu appears near cursor:
  ```
  ┌─────────────────────────┐
  │  Surah Al-Baqarah · 5  │  ← ayah header
  ├─────────────────────────┤
  │  ▶  Play this Ayah      │  ← play one, stop after
  │  ▶▶ Play from here      │  ← continuous auto-advance
  │  🔖 Bookmark            │  ← Phase 4
  └─────────────────────────┘
  ```
- Menu closes on: click outside, scroll, page change, Escape key
- Menu stays within viewport (flips direction if near screen edge)
- Only one menu open at a time

### Audio Player Bar (in Sidebar)
- Appears only when audio is active (hidden when nothing playing)
- Shows: currently playing surah name + ayah number
- Controls:
  - ▶ / ⏸ Play / Pause
  - ⏹ Stop (clears playing state completely)
  - ⏮ Previous Ayah
  - ⏭ Next Ayah
  - 🔁 Auto-advance toggle (on = keep playing, off = stop after one ayah)
- Progress bar: current time / total duration (seek-able)
- Playback speed selector: 0.75x · 1x · 1.25x · 1.5x

### Auto-Advance Logic
- When ayah ends → if auto-advance ON → play next ayah
- Increment ayah number; if past surah's last ayah → move to surah + 1, ayah 1
- If playing ayah is on a different page than current page → auto-navigate to that page
- At Quran end (114:6) → stop

### Highlighted Ayah While Playing
- `playingAyah` state: `{ surah, ayah }` — separate from `clickedAyah`
- Playing ayah gets a distinct highlight color (e.g. green tint) vs hover (yellow)
- Highlight moves automatically as auto-advance progresses

### Audio State
- `playingAyah`: `{ surah, ayah, displayAyah }` or `null`
- `isPlaying`: boolean
- `autoAdvance`: boolean (default `true`)
- These are independent of `clickedAyah` (selection vs playback are separate)

### Keyboard Shortcuts
- `Space` → Play / Pause
- `Escape` → Stop
- `→` → Next Ayah
- `←` → Previous Ayah

## Phase 4 — Bookmarks & Reading Progress

### Last Read
- On every page change, save page to `localStorage`
- On app load, offer "Continue from page X" prompt

### Bookmarks
- Right-click context menu "Bookmark" option → saves position
- Bookmarks list in sidebar — click to jump to that page
- Stored in `localStorage` as array of `{ page, surah, ayah, label, date }`
- Max 50 bookmarks
- Optional: custom label/note per bookmark
- Add/remove indicator on currently bookmarked page
